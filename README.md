# Evolved Cellular Automata for Procedural Level Generation

A **procedural content generation (PCG)** prototype that uses a **genetic algorithm (GA)** to evolve **cellular automata (CA) rules** for generating maze-like 2D game levels.

## Results

* **6 experiments**
* **60 levels generated**
* **58/60 playable levels**
* Rules evolved to work across **multiple random initial configurations**
* Generated levels target **long solution paths, many dead ends, maze-like structures, and minimal unreachable areas**

The project explores whether a single evolved CA rule can reliably transform different random starting states into playable game levels.
